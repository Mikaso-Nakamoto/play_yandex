# AGENTS.md — инструкция для ИИ-агентов

«Мяу-шарики» (EN: Meow Bubbles, TR: Miyav Baloncukları) — HTML5-игра в жанре «шарики» (bubble shooter: стреляем шариками, собираем 3+ одного цвета) для **Яндекс Игр**.
Цель проекта — доход (реклама + покупки), поэтому важны модерация, удержание игроков и время в игре.
Подробное руководство владельца — [`README.md`](README.md).

## Общение
- С владельцем проекта — **на русском**. Комментарии в коде тоже на русском (так принято в проекте).
- Если пользователь не просил иного, ключевой арт `promo/src/keyart.png` (выбран владельцем) не заменять. Он — эталон стиля для любой новой графики.

## Команды
| Команда | Что делает |
|---|---|
| `npm run dev` | dev-сервер `src/` + мок-SDK на :8080 (`--port`, `--nosdk`) |
| `npm run build` | сборка в `dist/` (esbuild, ES2015) **и** архив `release/meow-bubbles-yandex-v<версия>.zip` |
| `npm run preview` | сборка + сервер для `dist/` |
| `npm test` | логика: сетка, физика, уровни, таблица баланса (19 проверок) |
| `npm run test:flow` | сквозные сценарии в браузере: SDK, пауза, реклама, покупки, язык, поворот (18 сценариев) |
| `npm run test:soak` | долгая сессия ботом: утечки памяти/DOM, ошибки консоли |
| `npm run promo:texts` | тексты черновика укладываются в ограничения консоли |
| `npm run simulate` / `npm run levels` | симуляция прохождения / перегенерация таблицы 1000 уровней |
| `npm run promo:shots` / `promo:video` / `promo:art` / `promo:iap` | скриншоты, видео, иконка и обложки, иконки покупок |
| `node tools/repro-late-ad.mjs` | воспроизведение замечания аудита М1 (реклама, открывшаяся поздно) |
| `node tools/concept-preview.mjs` | превью нового фона в игре без изменения кода (`BG=… LEVEL=… SEED=…`) |

Браузерным инструментам нужен Chromium: переменная `CHROME_PATH` или `@sparticuz/chromium` в `TOOLS_NODE_MODULES` (см. `tools/browser.mjs`).
Параметры мок-SDK в URL: `lang`, `auth=1`, `fastads=1`, `adfail=1`, `rv=close`, `nopay=1`, `dayshift=N`, `test=1` (открывает `window.__bot` для тестов).

## Структура
- `src/` — игра. Это единственное, что попадает в архив.
  - `main.js` — загрузка: SDK → язык → игрок/сохранения → покупки → интерфейс → `LoadingAPI.ready()`.
  - `app.js` — экраны, попапы, реклама, магазин, пауза.
  - `core/` — `platform.js` (вся работа с SDK), `storage.js` (локальные и облачные сохранения), `i18n.js` (ru/en/tr), `audio.js` (WebAudio), `rng.js`.
  - `game/` — движок, рендер canvas, процедурная графика (`art.js`), бот, уровни, `level-table`.
  - `ui/` — карта уровней (`hub.js`), HUD, попапы, иконки.
- `tools/` — сборка, dev-сервер, мок-SDK, тесты, промо-конвейер (детерминированное виртуальное время `vtime.js` + `promo-lib.mjs`).
- `promo/` — материалы для консоли: тексты ru/en/tr, иконка, обложки, скриншоты, видео, покупки (`purchases.csv`).
- `docs/` — [`yandex-audit.md`](docs/yandex-audit.md) (аудит модерации), [`commercial-plan.md`](docs/commercial-plan.md) (план развития), `concept/`.
- `skills/` — навыки для агентов, оглавление в [`skills/README.md`](skills/README.md). В сборку не входят.
- `release/` — готовый архив для загрузки в консоль (коммитится).

## Цикл изменений
1. Правка в `src/`. Новые строки интерфейса — сразу на трёх языках в `src/core/i18n.js`.
2. `npm run build`.
3. `npm test` + `npm run test:flow` (+ `npm run test:soak` при изменениях рендера, эффектов или памяти).
4. Если изменился вид игры — перегенерировать затронутые промо.
5. Коммит. Если `src/` не менялся, а сборка лишь перепаковала архив (новые даты файлов), верните архив: `git checkout -- release/`.

## Правила Яндекс Игр (нарушать нельзя)
- **Реклама и покупки — только через SDK** (`src/core/platform.js`).
  - Межуровневая реклама — только в паузах.
  - Кнопка видео за награду пишет «за просмотр рекламы» и какую награду даёт; награда выдаётся только по `onRewarded`.
- **Пауза:** на время рекламы, при скрытии вкладки, потере фокуса и `game_api_pause` игра и звук на паузе. `GameplayAPI.start/stop` — только вокруг активной игры.
- **Покупки:**
  - начислить → сохранить (с `flush` в облако) → только потом `consumePurchase`;
  - при запуске обработать `getPurchases()` (1.13.1);
  - список в игре = вкладка «Инап-покупки» = `promo/iap/purchases.csv`.
- **Тексты:**
  - язык только из SDK;
  - название одинаково в игре и на всех материалах для каждого языка (5.1.3);
  - валюта не похожа на реальные деньги (3.7).
- **Нельзя:** внешние ссылки, e-mail и QR в игре, сторонние CDN/скрипты/шрифты, прокрутка страницы, контекстное меню, авторизация без нажатия кнопки.
- **Архив:** `index.html` в корне, имена файлов латиницей, ≤ 100 МБ (держим первую загрузку маленькой).
- **Облако:** `setData` не чаще лимита (≤ 100 вызовов / 5 мин, ≤ 200 КБ). Уже реализовано в `storage.js`, не обходить.

- Остальные полезные навыки (качество, «сочность», дизайн интерфейса) перечислены в `skills/README.md`.
