# Дизайн-система «Мяу-шариков» — тема «Сказочный луг»

Единые правила оформления игры. Эталон стиля — ключевой арт [`promo/src/keyart.png`](../promo/src/keyart.png), выбранный владельцем.
Правила собраны из скиллов [`skills/`](../skills/README.md) (`frontend-design`, `refactoring-ui`, `beautiful-shadows`, `animation-systems`, `apple-hig-design`, `build-hybrid-game-assets`) и адаптированы под казуальную игру.

## 1. Арт-дирекшн
- **Стиль:** мягкая рисованная книжная иллюстрация (гуашь/акварель), тёплый солнечный свет, округлые дружелюбные формы.
  Пример — пушистый рыжий кот и глянцевые шарики, как на ключевом арте.
- **Главное правило — один стиль на всё.**
  - Фоны, персонажи, иконки и интерфейс должны выглядеть как части одной иллюстрации.
  - Векторная или «эмодзи» графика рядом с рисованной сразу выдаёт MVP.
- **Анти-шаблон** (`frontend-design`): никакого «общего фиолетового», серых рамок и плоских белых карточек. У каждого элемента есть материал (бумага, конфета, стекло), глубина и обводка.

## 2. Палитра (60-30-10)
Палитра взята из ключевого арта:

| Доля | Роль | Где |
|---|---|---|
| 60 % | Небо и луг — рисованные фоны миров | `src/assets/bg/` |
| 30 % | Кремовая «бумага» окон, плиток и плашек | `--paper*`, `--tile*` |
| 10 % | Акценты: рыжий (кот), зелёный (главное действие), оранжевый (реклама/награда), голубой (информация), розовый (неудача/особое) | кнопки, ленты |

Токены (`src/style.css`, `:root`):

| Токен | Значение | Назначение |
|---|---|---|
| `--ink` | `#4b2e39` | основной текст и обводки — тёплый тёмно-коричневый, **не чёрный** (`refactoring-ui`) |
| `--ink-soft` | `#86624f` | второстепенный текст |
| `--ink-faint` | `#b39886` | подписи |
| `--paper1` / `--paper2` | `#fffaf0` / `#ffeed3` | поверхность окон (градиент сверху вниз) |
| `--paper-edge` / `--paper-shade` | `#ecca97` / `#d4a26a` | кромка окна и его «толщина» |
| `--tile`, `--tile-edge`, `--tile-shade` | `#fff6e6`, `#f1d6ab`, `#e6c08c` | плитки внутри окон (магазин, подарок дня, рекорды) |
| `--accent` / `--accent-ink` | `#ff8a3d` / `#c4562e` | рыжий акцент и его тёмный вариант для текста и иконок |
| `--line` | `rgba(75,46,57,.22)` | тонкая обводка элементов |
| `--warm` | `60,30,20` | цвет всех теней: `rgba(var(--warm), a)` — тени тёплые, не серые |
| `--green*`, `--orange*`, `--blue*`, `--pink*` | 1 светлый / 2 основной / 3 «толщина» | цветные кнопки и ленты |

**Смысл цветов кнопок:**
- зелёная — главное действие (Играть, Далее, Забрать);
- оранжевая — реклама за награду (на кнопке всегда «за просмотр рекламы»);
- голубая — покупка за монеты, вход;
- кремовая (`btn-gray`) — второстепенное;
- розовая лента — неудача или особое событие.

## 3. Типографика
- **Два шрифта**, оба встроены в архив:
  - **заголовочный** — M PLUS Rounded 1c 800 (`--font-display`, «Meow Rounded»): кнопки, ленты окон, числа (монеты, очки, номера уровней), заголовки, подписи меню;
  - **текстовый** — Nunito 800/900: описания и обычный текст.

  Оба поддерживают кириллицу, латиницу и турецкий (latin-ext), лицензия OFL.
- **Иерархия** через вес и цвет, а не только размер (`refactoring-ui`):
  - главное — `--ink` 900;
  - второстепенное — `--ink-soft`;
  - метки разделов — капсом с разрядкой (`.shop-sec`).
- **Текст на цветной кнопке или плашке:** белый, с мягкой тенью **того же оттенка, только темнее** (`0 .08em 0 var(--c3)`: тёмно-зелёная на зелёной, тёмно-оранжевая на оранжевой). Толстых обводок нет.
  На кремовой кнопке наоборот: тёмный текст `--ink` со светлой тенью.
- **Заголовки поверх картинки** («Уровень 14», подписи меню на карте): белый текст с тонкой обводкой `var(--outline-soft)` и мягкой тенью — ровно столько, сколько нужно для читаемости.
  - Обводка задана в `em`, поэтому масштабируется с текстом.
  - Не использовать `-webkit-text-stroke`: на iOS он рисуется внутрь и съедает буквы.

## 4. Глубина и материалы
Тени многослойные (`beautiful-shadows`), всегда тёплые.

| Элемент | Рецепт |
|---|---|
| **Кнопки (`.btn-*`)** | «мягкий мат» на CSS: градиент своего цвета `--c1 → --c2`, тонкий блик сверху (`::after`, 22 % → 3 %), объёмный край `0 .26em 0 var(--c3)`, мягкая тень. Без большой глянцевой полосы и тёмной обводки. Нажатие: `translateY(3px) scale(.98)` |
| **Круглые кнопки (`.round`)** | тот же рецепт плюс белый кант `0 0 0 .12em`, белая иконка. Цвет по назначению: оранжевая — пауза/настройки, красная — закрыть, зелёная — магазин, розовая — подарок, синяя — бесконечный режим, золотая — рекорды |
| **Заголовки окон (`.card-title`, `.world-banner`)** | плашка своего цвета с белым кантом и объёмным краем, без хвостов |
| **Узлы карты** | тот же рецепт в виде круга: золотой (пройден), зелёный со свечением (текущий), кремовый с замком (закрыт); номер — заголовочным шрифтом |
| **Иконки** | монета-лапка, бомба, радуга, огненный шар — нарисованные PNG в SVG-обёртке `P('coin')` (`src/ui/icons.js`). Простые знаки (пауза, шестерёнка, крестик) — векторные белые |
| **Кот** | нарисованный спрайт в трёх эмоциях (`src/assets/cat/idle|happy|sad.png`, одинаковый масштаб). Оживление в коде: дыхание, прыжки от радости, оседание в грусти. Грустный кот — в окнах «шарики закончились» и «уровень не пройден» |
| **Окно (`.card`)** | внутренний белый кант `inset 0 0 0 .2em` → кромка `0 0 0 .2em var(--paper-edge)` → «толщина» `0 .5em 0 .2em var(--paper-shade)` → мягкая тень `0 1.2em 2.4em rgba(var(--warm),.4)` |
| **Лента заголовка (`.card-title`)** | белый кант + обводка + «толщина» цвета ленты |
| **Плашки HUD (`.pill`)** | кремовое «стекло» + белый кант + обводка + внутренняя тень снизу. Иконка крупнее плашки и «выглядывает» за её левый край. Числа — заголовочным шрифтом |
| **Тропинка карты** | тёплая кромка → песок → светлые «камешки» (`src/ui/hub.js`) |

### Мера глянца — решение владельца (17.10.2026)
| Вариант | Оценка владельца |
|---|---|
| Простые CSS-кнопки, векторный кот и значки | «топорно» |
| Полностью нарисованный глянцевый набор: кнопки 3-slice, шары-кнопки, ленты с хвостами, толстые обводки текста | «слишком глянцево и вычурно» |
| **Принят — «мягкий мат»:** рисованные фоны, кот и иконки + аккуратные CSS-кнопки без большого глянца | средний вариант |

Сравнение трёх вариантов: [`design/gloss-variants.jpg`](design/gloss-variants.jpg). Глянцевый набор не удалён: исходники лежат в `promo/src/ui/`, вернуть его можно командой `bash tools/art/make-ui.sh --kit`.
**Правило:** на одном элементе не больше одного блика; обводка текста — только поверх картинок.

## 5. Движение
Значения взяты из скилла `animation-systems`:

| Что | Длительность | Кривая |
|---|---|---|
| Нажатия | 80–120 мс | ease-out |
| Появление окон (`popIn`) | 320 мс | лёгкий overshoot `cubic-bezier(.2,1.4,.4,1)` |
| Закрытие | 180 мс, быстрее появления | — |
| Звёзды победы | по очереди | пружина |
| Лучи за звёздами | вращение 16 с | — |
| Пульсация текущего узла и сегодняшнего подарка | 1,2 с | — |

- Каскад появления элементов — 40–90 мс.
- `prefers-reduced-motion`: декоративные анимации отключаются (лучи), игровые остаются короткими.

## 6. Касания и раскладка
- Зоны касания: цель — 44 px (`apple-hig-design`). Круглые кнопки — 3,1 em (≈ 40–56 px). Жёсткий минимум на самом маленьком экране — 36 px (`max(…em, 36px)`). Строки настроек нажимаются целиком (≥ 44 px).
- Размер шрифта интерфейса задаёт JS: `fs = clamp(min(W/25, H/40), 11, 18)` px на `body`, всё остальное — в `em`. Мелкие подписи не опускаются ниже 10,5 px, надпись «за просмотр рекламы» — ниже 11 px.
- Безопасные зоны: вырез сверху и полоска жеста снизу (`env(safe-area-inset-*)`) учтены в раскладке поля и в CSS карты и окон.
- Проверка: `npm run test:devices` — 18 размеров телефонов, скриншоты и сводные листы в `.tmp/devices/`.

## 7. Рисованные ресурсы (конвейер)
Порядок работы — по скиллу `build-hybrid-game-assets`:
1. **Генерация** по ключевому арту как референсу (и по уже готовому фону мира — для единства).
   Промпт: сцена мира + требования композиции + запреты «без персонажей, без текста, без интерфейса, без рамки».
   Промпты всех ресурсов — в [`docs/art/PROVENANCE.md`](art/PROVENANCE.md).
2. **Композиция фона:**
   - **Вертикальный 9:16:** верхние ~55 % — спокойное небо (там шарики); середина — даль; нижние ~25 % — передний план только по краям, свободное место внизу слева (кот) и по центру (пушка).
   - **Горизонтальный 16:9:** спокойная центральная треть (там поле), детали по бокам и внизу.
3. **Обработка:**
   - мастер-файлы — JPEG q93 в `promo/src/bg/`;
   - игровые — JPEG q84 в `src/assets/bg/w<мир>-<p|l>.jpg`, 768×1376 / 1376×768, 60–150 КБ;
   - имена только латиницей.
4. **Интерфейс, персонажи и иконки:** генерация на однотонном фоне — зелёном `#00FF00`; пурпурном — для зелёных объектов; белом — для объектов с тёмной обводкой.
   - Исходники хранятся без потерь в `promo/src/ui/*.webp`.
   - Вырезание — `tools/art/cutout.py`: мягкий край, подавление цветной каймы, обрезка по содержимому, 256-цветный PNG с альфой. Файлы в 5–12 раз меньше: иконки и кот ≈ 130 КБ.
   - Цветовые варианты — сдвиг тона одной картинки (`--hue/--sat/--val`), а не новая генерация.
   - Пересборка иконок и кота — `bash tools/art/make-ui.sh`; глянцевый набор кнопок — `--kit` (сейчас не используется).
5. **Подключение:** `src/core/assets.js` (ленивая загрузка). Пока картинки нет, рисуется процедурный фон (`art.js`), игра никогда не ждёт сеть.
   - Стартовый мир грузится во время экрана загрузки (не дольше 1,5 с), следующий — фоном.
   - Для мира без горизонтального фона широкий кадр собирается из вертикального: зеркальные копии + мягкое размытие по краям, чёткая картинка по центру.
6. **Проверка:**
   - `node tools/concept-preview.mjs` — сравнение «до/после» без правки кода;
   - `node tools/screens.mjs <папка> <url>` — все экраны;
   - `npm run promo:shots` — промо-скриншоты.

## 8. Чеклист перед сдачей изменений оформления
- [ ] Новый элемент использует токены из `:root`, а не «сырые» цвета; чистого чёрного нет.
- [ ] Есть состояния: обычное, нажатие, неактивное, фокус с клавиатуры.
- [ ] Читается на самом светлом (снег) и самом тёмном (ночь) мирах.
- [ ] Телефон 320×568, 390×844, ландшафт 844×390, планшет, 1280×720, 1920×1080 — `tools/screens.mjs` (`VPS=phone,small,land,tablet,desk,fhd`).
- [ ] `npm run test:devices` зелёный: на всех телефонах ничего не налезает, не обрезается и нажимается (для турецкого — `LANG_UI=tr`).
- [ ] Иерархия видна за 3 секунды: что главное на экране, куда нажать (`frontend-design`).
- [ ] Тексты на всех языках помещаются: турецкие длиннее русских на 10–25 %.
- [ ] `npm test`, `npm run test:flow`, `npm run test:soak` зелёные. После изменения вида — `npm run promo:shots` и `npm run promo:video`.
