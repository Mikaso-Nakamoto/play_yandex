## Средние замечания

### М1. Реклама, открывшаяся позже таймаута, не ставит игру и звук на паузу
- **Правило/раздел:** раздел 4 требований (реклама): на время полноэкранной рекламы игра и звук должны быть на паузе. Раздел 1 (звук).
- **Файл и строки:**
  - Полноэкранная реклама: `src/core/platform.js:143` (таймер-страховка 6 с) и `:149` (`onOpen`).
  - Реклама за вознаграждение: `src/core/platform.js:175` (8 с) и `:181`.
- **Что не так:**
  - Страховка нужна, чтобы игра не зависла, если SDK не ответит. Через 6 с она снимает паузу и выходит из ожидания.
  - Если SDK всё-таки откроет рекламу позже (медленная сеть), `onOpen` только ставит флаг. Пауза не возвращается, и игра со звуком идёт под рекламой.
  - У видео за вознаграждение то же самое. Вдобавок награда за досмотренное «позднее» видео не выдаётся: промис уже завершился со статусом `error`.
- **Доказательство** (`node tools/repro-late-ad.mjs`; мок-SDK вызывает `onOpen` через 7 с и `onClose` через 10 с):
  ```
  1 с: реклама запрошена         {"pause":["ad"]}
  6.6 с: сработал таймаут        {"pause":[]}
  7.8 с: РЕКЛАМА НА ЭКРАНЕ       {"pause":[], "log":["resolved:false","onOpen@7s"]}   ← игра не на паузе
  ```
- **Почему это риск модерации:** модераторы проверяют игру в том числе на слабом соединении. Звук или движение игры во время рекламы — типичная причина отклонения. Для игрока это тоже выглядит как ошибка: у него может «сгореть» ход.
- **Как исправить:**
  - Если `onOpen` пришёл после таймаута, снова поставить паузу (`adStart`). На `onClose`/`onError` снять её (`adEnd`).
  - Для видео за вознаграждение увеличить страховку до ~12 с. Так снизится вероятность «позднего» видео без награды.
- **Пример исправления:** см. раздел «Рекомендуемые правки», п. 1.

### М2. Загрузчик показывает русское название до определения языка
- **Правило/раздел:**
  - 5.1.3: название игры одинаково в игре и на всех материалах для каждого языка.
  - Раздел 8: все тексты переведены.
- **Файл и строки:**
  - `src/index.html:20`: `<div class="loader-logo">Мяу-шарики</div>`.
  - `src/index.html:9`: `<title>`.
  - Локализованное название ставится позже, в `src/main.js:44-46`, после `platform.init()`.
- **Что не так:** первые ~0,3–1 с (пока грузится `game.js` и инициализируется SDK) EN- и TR-игрок видит на экране загрузки «Мяу-шарики» вместо «Meow Bubbles» / «Miyav Baloncukları».
- **Почему это риск модерации:** модератор проверяет каждую языковую версию, и первое, что он видит, — экран загрузки. Если там название на другом языке, это прямое несоответствие 5.1.3 и п. 8 («все тексты переведены»).
- **Как исправить:** до определения языка не показывать текст в загрузчике (оставить анимацию точек). `main.js` уже подставляет локализованное название после `setLang`.
- **Пример исправления:** см. раздел «Рекомендуемые правки», п. 2.

- **Н6. Первый межуровневый показ** — не раньше 65 с после запуска и с 3-го уровня (`src/app.js:23-24,35`). Это хорошо для удержания. Менять не нужно, просто фиксирую.

## Рекомендуемые правки
Ниже конкретные правки. В рамках аудита они **не внесены**.

**1. М1 — пауза при «поздней» рекламе** (`src/core/platform.js`, `showInterstitial` и `showRewarded`):
```js
// showInterstitial(): реклама открылась уже после таймаута — снова ставим игру на паузу
let late = false;
const lateEnd = () => { late = false; if (this.adActive) { this.adActive = false; this.emit('adEnd'); } };
// ...
callbacks: {
  onOpen: () => {
    opened = true;
    if (done) { late = true; this.adActive = true; this.emit('adStart'); }
  },
  onClose: (wasShown) => { if (late) { lateEnd(); this.lastInterstitial = Date.now(); return; } finish(wasShown); },
  onError: () => { if (late) { lateEnd(); return; } finish(false); },
  onOffline: () => { if (late) { lateEnd(); return; } finish(false); },
},
```
То же для `showRewarded()`:
- страховку поднять с 8000 до 12000 мс;
- поздний `onOpen` → `adStart`, `onClose`/`onError` → `adEnd`.
