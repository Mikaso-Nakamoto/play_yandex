# Мяу-шарики — бабл-шутер для Яндекс Игр

**Мяу-шарики** (en: *Meow Bubbles*, tr: *Miyav Baloncukları*) — HTML5-игра в жанре бабл-шутер (стрелялка шариками), сделанная под требования [Яндекс Игр](https://yandex.ru/dev/games/doc/ru/concepts/requirements). Игрок помогает рыжему коту освобождать котят из разноцветных пузырей.

Архив для загрузки уже собран: **`release/meow-bubbles-yandex-v1.1.0.zip`** (~1,3 МБ, `index.html` в корне). Промо-материалы и тексты черновика на трёх языках лежат в папке `promo/`.

## 1. Что внутри

**Игра**
- Классический бабл-шутер на гексагональном поле: 3+ шарика одного цвета лопаются, всё, что на них держалось, падает.
- Два типа уровней: «спаси всех котят» и «лопни все шарики». Количество выстрелов ограничено, за остаток дают очки и звёзды (1–3).
- Уровни генерируются детерминированно и откалиброваны ботом (таблица на 1000 уровней, дальше игра продолжается без конца). Сложность растёт плавно: больше цветов, камни (с 12-го уровня), бомбы на поле (с 7-го).
- 8 миров со своим оформлением, по 15 уровней. Миры повторяются по кругу.
- Бустеры: бомба, радуга, огненный шар.
- Бесконечный режим (ряды опускаются после промахов) с таблицей рекордов.
- Ежедневные подарки (серия из 7 дней), звёзды, монеты.
- Обучение на уровнях 1–4 и 6: прицел, котята, смена шарика, бустеры, отскок от стенки.
- Управление пальцем, мышью и с клавиатуры (Пробел/S — смена шарика, 1/2/3 — бустеры, Esc — пауза).
- Три языка (ru/en/tr), язык выбирается автоматически из SDK.
- Звук и музыка синтезируются в Web Audio (без аудиофайлов). Звук выключается при сворачивании вкладки и во время рекламы.
- Сохранения в облаке Яндекса (`player.setData`) и в `localStorage`.

**Монетизация** (подробно в [разделе 5](#5-монетизация-как-устроена-и-что-настраивать))
- Полноэкранная реклама между уровнями (не чаще раза в 65 с, не раньше 3-го уровня).
- Видео за вознаграждение: +5 выстрелов, ×2 монеты за уровень, ×2 ежедневный подарок, бустер, монеты в магазине, продолжение бесконечного режима.
- Sticky-баннер.
- Инап-покупки: «Без рекламы» и наборы монет/бустеров.

**Техника**
- Чистый JavaScript + Canvas 2D, без фреймворков, бандл через esbuild. Нет внешних запросов, кроме `/sdk.js`.
- Шрифт Nunito лежит в архиве (woff2), картинки рисуются кодом.
- Адаптивная вёрстка: телефоны в портрете и альбоме, планшеты, десктоп. Без прокрутки, без контекстного меню и выделения текста.

## 2. Быстрый старт

Нужен Node.js 18+ (проверено на 22).

```bash
npm install
npm run dev        # http://localhost:8080 — игра из src/ с мок-SDK
npm test           # логические тесты (поле, правила, уровни, сохранения)
npm run build      # dist/ + release/meow-bubbles-yandex-v<версия>.zip
npm run preview    # сборка и запуск dist/ на http://localhost:8080
```

Локально вместо настоящего SDK работает мок `tools/mock-sdk.js`: внизу справа есть панель с журналом вызовов. Полезные параметры адреса:

| Параметр | Что делает |
| --- | --- |
| `?lang=en` / `?lang=tr` | язык окружения |
| `?auth=1` | игрок авторизован (облако, лидерборд) |
| `?fastads=1` | короткая реклама без ограничения частоты |
| `?adfail=1` | реклама возвращает ошибку |
| `?rv=close` | видео закрывают до награды |
| `?nopay=1` | покупки недоступны |
| `?dayshift=1` | сдвиг серверного времени на N дней (проверка ежедневных подарков) |
| `?test=1` | открывает `window.__app` для автотестов |

## 4. Публикация: пошагово

### 4.1. Аккаунт разработчика
1. Войдите в [Консоль разработчика](https://games.yandex.ru/console) с Яндекс ID и заполните профиль.
2. **Реклама.** Чтобы получать доход, подключите монетизацию: зарегистрируйтесь в РСЯ и примите оферту (раздел [«Монетизация»](https://yandex.ru/dev/games/doc/ru/console/adv-monetization) в документации).
3. **Покупки.** Для инапов нужна **Единая лицензионная схема** (Профиль → «Единая лицензионная схема»). Пока статус не «Активен», не отправляйте на модерацию версию с покупками. Если ЕЛС недоступна, покупки подключают письмом на games-partners@yandex-team.ru (название и ID игры). Подробно: [«Инап-покупки»](https://yandex.ru/dev/games/doc/ru/console/purchases).

> Если покупки пока не подключены, игру можно публиковать без них: магазин покажет только монеты за рекламу и бустеры за монеты, а пустые карточки покупок не появятся.

### 4.2. Новая игра и архив
1. Консоль → **Игры** → **Добавить игру**.
2. На вкладке **Черновик** загрузите `release/meow-bubbles-yandex-v1.1.0.zip`.

### 4.3. Поля черновика
Все тексты готовы, их нужно только скопировать:

| Что | Откуда |
| --- | --- |
| Название, SEO-описание, короткое описание, «Об игре», «Как играть», ключевые слова | `promo/texts/ru.md`, `en.md`, `tr.md` — для каждого языка свой файл |
| Платформы, ориентация, категории, теги, рейтинг, список файлов для загрузки | `promo/texts/common.md` |
| Комментарий разработчика для модераторов | `promo/texts/common.md`, последний блок |

Важно:
- **Название в каждом языке должно совпадать с названием в игре и на обложке** (п. 5.1.3): «Мяу-шарики», «Meow Bubbles», «Miyav Baloncukları». Если захотите переименовать игру, поменяйте ключ `title` в `src/core/i18n.js`, обложки (`npm run promo:art`) и тексты.
- Перед отправкой проверьте, что названия уникальны в каталоге (п. 5.12): поищите их на yandex.ru/games. Если такое название уже занято, придумайте другое и обновите игру, обложки и тексты.
- Тексты не должны повторяться между полями (п. 5.11). Длину и правила проверяет `npm run promo:texts`.

### 4.4. Изображения и видео
| Поле консоли | Файл | Примечание |
| --- | --- | --- |
| Иконка 512×512 | `promo/icon/icon-512.png` | без текста, без рамок и скруглений |
| Обложка 800×470 | `promo/cover/cover-800x470-<язык>.png` | для каждого языка своя, с названием на нужном языке |
| Скриншоты, мобильные (портрет) | `promo/screenshots/<язык>/mobile-01…04-*.jpg` | нужно минимум 2 на каждую выбранную платформу |
| Скриншоты, десктоп | `promo/screenshots/<язык>/desktop-01…04-*.jpg` | только горизонтальные |
| **Горизонтальное видео (обязательно)** | `promo/video/horizontal-<язык>.mp4` | 16:9, 1920×1080, ~26 с (лимит 28 с) |
| Вертикальное видео (необязательно) | `promo/video/vertical-<язык>.mp4` | 9:16, 1080×1920 |

На всех скриншотах и в видео только настоящий геймплей: играет бот, без монтажа и без интерфейса SDK. Скриншоты `*-05-map.jpg` (карта уровней) можно добавить пятыми, но не вместо игровых (п. 5.1.1.2 — минимум 70% геймплея).

Необязательные поля «Маскируемая иконка» и «Обложка на витрину» (1560×520) можно оставить пустыми.

### 4.5. Настройки игры
- **Облачные сохранения — включить.** Игра пишет прогресс через `player.setData`.
- **Ориентация на мобильных — «Портретная».** Мобильные скриншоты и вертикальное видео тоже портретные.
- **Платформы:** десктоп и мобильные. ТВ не включайте.
- **Языки:** русский, английский, турецкий. Модерация проверяет каждый язык, проверить можно через отладочную панель: откройте черновик с `?debug-mode=16`.

### 4.6. Реклама
1. Вкладка **Реклама**: включите **sticky-баннеры** (позицию на мобильных и десктопе выберите сами, обычно снизу или сбоку).
2. Включите опцию **«Показывать sticky-баннер через API»**. Игра сама вызывает `showBannerAdv()` при запуске и `hideBannerAdv()` после покупки «Без рекламы». Без этой опции баннер показывается автоматически, и игра им не управляет: после покупки «Без рекламы» он может остаться.
3. Полноэкранная реклама и видео за награду работают сразу, отдельно настраивать их не нужно.

### 4.7. Таблица рекордов
Вкладка **Лидерборды** → создать:
- техническое название: **`endless`** (именно так, в коде `LB_NAME` в `src/core/platform.js`);
- тип: числовой, «Больше — лучше», без десятичных знаков;
- название: «Бесконечный режим» / «Endless mode» / «Sonsuz mod».

Рекорды отправляют только авторизованные игроки. Кнопка входа находится в настройках игры.

### 4.8. Инап-покупки
1. Вкладка **Инап-покупки → Инапы → Загрузить CSV-файл** → `promo/iap/purchases.csv`. Если консоль не примет файл, сравните заголовки с примером по ссылке «Скачать пример»; поля можно ввести и вручную.
2. Загрузите иконки 256×256 из `promo/iap/icon-<id>.png` для каждой покупки.
3. **Инап-покупки → Настройки → Список логинов для тестовых покупок**: добавьте свой логин, тестовые покупки бесплатны.

| ID | Что получает игрок | Цена (предложение) | Тип |
| --- | --- | --- | --- |
| `noads` | без межуровневой рекламы и баннера (видео за награду остаются по желанию) | 99 ян | постоянная |
| `coins500` | 500 монет | 29 ян | расходуемая |
| `coins1500` | 1500 монет | 69 ян | расходуемая |
| `coins5000` | 5000 монет | 179 ян | расходуемая |
| `boosters3` | по 3 бомбы, радуги и огненных шара | 49 ян | расходуемая, по желанию |

Игра понимает любые ID вида `coins<N>` (N монет) и `boosters<N>` (по N бустеров каждого вида), так что пакеты можно менять без правки кода. **Список покупок в игре берётся из консоли**, поэтому он всегда совпадает с вкладкой «Инап-покупки» (п. 1.13.4). Если `boosters3` не добавите, уберите её из комментария для модераторов.

Как работает начисление: награда сохраняется (в том числе в облако), и только потом вызывается `consumePurchase`. Необработанные покупки проверяются при каждом запуске и после входа в аккаунт. Цена выводится числом с иконкой валюты из SDK.

### 4.9. Проверка черновика
Откройте игру в режиме черновика (кнопка в консоли), затем проверьте ещё раз с `?debug-mode=16` в адресе:
- значок **Game Ready** зелёный (вызывается `LoadingAPI.ready()`);
- разметка **GameplayAPI** (start/stop) приходит при старте уровня, паузе, окнах, рекламе;
- переключение языков ru/en/tr;
- реклама: полноэкранная после 3-го уровня, видео за награду, баннер;
- тестовая покупка «Без рекламы» убирает баннер и межуровневую рекламу и сохраняется после перезапуска;
- вход в аккаунт и таблица рекордов в бесконечном режиме.

### 4.10. Модерация
Нажмите **Отправить на модерацию** (можно с опцией «Отсроченная публикация»). Обычно проверка занимает 3–5 рабочих дней. Если игру отклонят, причина придёт на почту: исправьте и отправьте снова. Перед отправкой пройдите [чек-лист](#9-чек-лист-перед-модерацией).

## 5. Монетизация: как устроена и что настраивать

| Формат | Где показывается | Ограничения |
| --- | --- | --- |
| Полноэкранная (interstitial) | перед стартом уровня (кнопки «Играть», «Далее», «Повторить»), при выходе на карту из уровня, перед бесконечным режимом | не чаще раза в 65 с; до 3-го уровня только перед бесконечным режимом; не после покупки `noads`. Игра и звук на паузе |
| Видео за награду | кнопки с подписью «за просмотр рекламы» | награда только после `onRewarded`; это всегда бонус, игра проходима без рекламы |
| Sticky-баннер | по API при запуске | скрывается после покупки `noads` |
| Покупки | магазин (кнопка на карте и «+» у монет), предложение купить монеты при нехватке | список из консоли |

Константы в начале `src/app.js`:
- `INTERSTITIAL_GAP = 65000` — минимальный интервал между полноэкранными показами, мс. У платформы есть собственный лимит частоты, поэтому сильно уменьшать интервал бессмысленно.
- `FIRST_AD_LEVEL = 3` — с какого уровня показывать межуровневую рекламу.
- `RV_COINS = 50` — монеты за видео в магазине.
- `BOOSTER_PRICE`, `CONTINUE_PRICES` — цены в монетах.
- Ежедневные подарки — массив в начале файла.

**Что влияет на доход.** Каталог продвигает игры с хорошими рейтингом, удержанием, временем в игре и долей вернувшихся игроков. Для этого в игре есть короткие уровни, звёзды, ежедневные подарки, миры, бесконечный режим с рекордами и облачные сохранения. После публикации:
- смотрите в консоли воронку по уровням: где игроки бросают, там уровни слишком сложные. Сложность настраивается в `src/game/levels.js`, после правок пересоберите таблицу: `npm run levels`;
- запускайте A/B-тесты иконки и обложки в консоли: от них сильно зависит кликабельность в каталоге;
- выпускайте обновления (новые миры, события). Интервал рекламы лучше не уменьшать: частая реклама снижает удержание и рейтинг.

## 6. Промо-материалы

Все материалы пересобираются скриптами:

| Команда | Что делает | Выход |
| --- | --- | --- |
| `npm run promo:art` | иконка 512 и обложки 800×470 (без текста и с названием на ru/en/tr) из ключевого арта `promo/src/` | `promo/icon/`, `promo/cover/` |
| `npm run promo:shots` | 5 сцен × 3 языка × (мобильный портрет 1080×1920 + десктоп 1920×1080) | `promo/screenshots/<язык>/` |
| `npm run promo:video` | видео геймплея: два уровня целиком, 30 кадров/с, ~26 с | `promo/video/` |
| `npm run promo:iap` | иконки покупок 256×256 | `promo/iap/` |
| `npm run promo:texts` | проверка длины и правил текстов черновика | — |

Как это устроено: игра запускается в headless Chrome с «виртуальным временем» (`tools/vtime.js`). Бот прицеливается и стреляет, каждый кадр снимается отдельно, поэтому видео плавное на любой машине. Сцены детерминированы: при повторном запуске получаются те же кадры. Сцены и моменты съёмки задаются таблицами `SCENES` в `tools/promo-shots.mjs` и `SEGMENTS` в `tools/promo-video.mjs`.

Что нужно установить:
- **Google Chrome или Chromium.** Ищется автоматически, иначе укажите путь: `CHROME_PATH=/путь/к/chrome`.
- **ffmpeg с libx264** (только для видео): в `PATH`, через переменную `FFMPEG=/путь/к/ffmpeg` или `pip install imageio-ffmpeg`.

Ключевой арт и исходная иконка (`promo/src/`) сгенерированы ИИ заранее. Это разрешено правилами (п. 1.23), а скругления и рамки скрипт обрезает (п. 8.3.3).

## 7. Тесты и отладка

```bash
npm test             # логика: поле, совпадения, падения, бомбы, камни, уровни, сохранения
npm run test:flow    # 18 сценариев в браузере против мок-SDK: реклама, награды, покупки,
                     # пауза, языки, поворот экрана, ежедневный подарок, бесконечный режим
npm run test:soak    # долгая сессия ботом: рост памяти/DOM и ошибки консоли (поиск утечек)
node tools/play-test.mjs 3   # бот проходит уровни 1–3 в настоящем браузере (нужен npm run dev)
npm run simulate     # статистика прохождения уровней ботом
```

Браузерные тесты используют тот же поиск Chrome, что и промо-скрипты (см. раздел 6).

## 8. Обновление игры
1. Поменяйте версию в `src/app.js` (`VERSION`) и `package.json`.
2. `npm test && npm run test:flow && npm run build`, после чего в `release/` появится новый архив.
3. Консоль → игра → **Черновик** → загрузите архив → **Отправить на модерацию**. Пока идёт проверка, в каталоге остаётся предыдущая версия.
4. Если меняли покупки, сначала обновите их на вкладке «Инап-покупки», чтобы они совпадали с игрой.
5. Если поменяли название или внешний вид, обновите обложки, скриншоты и видео (`npm run promo:art`, `promo:shots`, `promo:video`).
